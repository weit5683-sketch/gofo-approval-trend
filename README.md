# GUS 审批时效趋势看板

按周展示 GUS 海外 OA 审批时效：各板块 / 各三级部门的平均审批时长趋势。
风格参考同组织的「GEU 考勤差错率看板」。

- 页面：`index.html`（单文件，Plotly 走 CDN）
- 生成脚本：`approval_trend_dashboard.py`，读取 `data_weekly.json` 输出 HTML
- 部署：GitHub Pages（main 分支根目录）

## 口径

- 平均审批时长 = Σ单次审批时长 ÷ 审批次数 × 24（小时）
- 部门 = 审批人三级部门（按工号匹配花名册）
- 已剔除：废弃单据、考勤异常申诉、起草节点、被考核人自评、GEU人力资源部、未匹配部门
- 周报按审批操作时间归属自然周；某部门某周无动作则折线断开

> 页面只含部门级聚合数据（部门名称、周均时长、次数），不含人员姓名。
